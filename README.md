A token launch radar that ranks the 758 protocols in the sealed snapshot by what a token launch would be worth. The value is fitted from the snapshot's own numbers (TVL, 7-day growth, age), with a calibrated 90% interval on every value, token odds from the peers' record, and a costed farm plan for each protocol.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
